# Mening Mahallam

O'zbek mahallalari uchun raqamli qo'shnichilik ilovasi.

Flutter ustida qurilgan mobil ilova — mahalla e'lonlari, muhokamalar, navbatchilik va yordam so'rovlarini bitta joyga jamlaydi. Firestore real-time sync bilan offline-first ishlaydi.

## Muammo

Mahalla hayoti hali ham qog'oz e'lonlar va og'izdan-og'izga tarqaladigan xabarlarga tayanadi. Internet doim barqaror bo'lmagan hududlarda odatdagi ilovalar ishlamay qoladi — shu bo'shliqni to'ldirish uchun ilova offline-first qilib loyihalandi.

## Stack

Flutter · Dart · Firebase · Firestore · FCM · Riverpod

## Asosiy funksiyalar

- **E'lonlar devori** — mahalla rahbariyati va qo'shnilar e'lon joylashtiradi, muhim xabarlar pin qilinadi
- **Muhokamalar** — har bir e'lon ostida threaded izohlar, real-time yangilanadi, offline'da qoralama saqlanadi
- **Yordam so'rovlari** — qo'shnidan yordam so'rash, kategoriya/masofa/shoshilinchlik bo'yicha saralanadi
- **Navbatchilik jadvali** — mahalla postlari va yig'in navbatchiligi, avtomatik eslatma bilan
