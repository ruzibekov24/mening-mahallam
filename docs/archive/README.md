# Arxiv — dastlabki reja hujjatlari

Bu papkadagi fayllar loyiha **kod yozilishidan oldin**, faqat g'oya va
reja bosqichida yozilgan (2024-2025). Ular tarixiy qiziqish uchun
saqlanmoqda — ko'p narsa haqiqiy ilovada boshqacha amalga oshirilgan
yoki umuman ishlatilmagan.

Joriy holat uchun repo tugunidagi [`README.md`](../../README.md) va
[`docs/roadmap.md`](../roadmap.md) ga qarang.
