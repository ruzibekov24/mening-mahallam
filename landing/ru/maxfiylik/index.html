Какие данные мы собираем

Для использования приложения «Mening Mahallam» запрашиваются следующие данные:

  • Номер телефона — для создания и подтверждения аккаунта (через Telegram-бот, не через SMS).
  • Имя и фамилия — для отображения в профиле и обращениях.
  • Фото профиля и баннер — по желанию, загружаете сами.
  • Местоположение — при отправке обращения, для отображения на карте (только с вашего разрешения).
  • Переписка — сообщения, отправленные соседям через чат в приложении.
  • Токен уведомлений — для отправки push-уведомлений на телефон (через Firebase Cloud Messaging).

Где хранятся ваши данные

Данные хранятся в зашифрованном виде в инфраструктуре Google Firebase (Firestore) и Supabase. Файлы (фотографии) хранятся в Supabase Storage.

Кто видит ваши данные

  • Имя, фото профиля и номер телефона (если вы разрешили его показ) видны только жителям вашей махалли.
  • Обращение с пометкой «приватное» видите только вы и руководство махалли (раис, сотрудники).
  • Публичное обращение видят все жители махалли.
  • Вашу переписку видит только собеседник.
  • Мы не продаём ваши данные третьим лицам и не используем их в рекламных целях.

Ваши возможности контроля

  • В Настройках можно отключить показ номера телефона другим жителям.
  • Можно отключить показ времени «последней активности».
  • Можно заблокировать любого пользователя.
  • Вы можете запросить у администратора удаление аккаунта и связанных данных (через Telegram @Ilyos_Ruzibekov).
